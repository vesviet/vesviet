> **Answer-first:** The AI category focuses on production AI engineering, Model Context Protocol (MCP) servers, autonomous LiteLLM multi-agent swarms, and high-performance Small Language Model (SLM) edge inference runtimes. Engineering teams deploying these architectures achieve sub-500ms time-to-first-token (TTFT), secure sandboxed tool execution, and scalable vector search using custom pure Go HNSW graph engines.

- **Model Context Protocol (MCP) & Generative UI:** Client-server context streaming, tool registries, and dynamic user interface generation via structured JSON.
- **RAG & Knowledge Retrieval Systems:** Vector indexing trade-offs, BM25 hybrid search, GraphRAG knowledge graphs, and custom Go vector database engines.
