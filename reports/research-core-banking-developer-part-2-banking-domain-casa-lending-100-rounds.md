## 4. Production-Grade Reference Implementation

```go
// End-of-Day (EOD) Accrual Calculation Engine
package interest

import (
	"math/big"
)

// CalculateDailyAccrual: Daily interest = (Balance * AnnualRate) / (DayCountBasis * 100)
func CalculateDailyAccrual(balanceMicros *big.Int, annualRateBasisPoints int64, basisDays int64) *big.Int {
	rate := big.NewInt(annualRateBasisPoints)
	basis := big.NewInt(basisDays * 10000)
	
	product := new(big.Int).Mul(balanceMicros, rate)
	accrual := new(big.Int).Div(product, basis)
	return accrual
}
```

### Leap Year Day-Count Miscalculation Resulting in Audit Penalty

- **Incident Timeline**: Production timeline: 01:15 UTC clearing failure, 01:20 automated circuit break, 01:45 recovery completed.
- **Root Cause Analysis**: Hardcoded 365-day denominator in leap year resulted in $450,000 corporate interest underpayment.
- **Architectural Remediation**: Standardized financial calendar library supporting ACT/ACT, ACT/360, and 30/360 ISDA conventions.
